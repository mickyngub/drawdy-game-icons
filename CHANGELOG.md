# Changelog

## 1.0.0

First public release

- Over 4,000 game icons from game-icons.net in twelve categories, with ranked search that understands gamer words like d20, hp, mana and loot
- Plain, Tile and Token styles, any colour, four sizes and an optional name label
- Drag an icon onto the board or click to add it in view; repeated clicks line up in rows
